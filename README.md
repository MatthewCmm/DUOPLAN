# DuoPlan

Organizador de tareas, calendario y finanzas para dos. Pensado para usarse desde el teléfono como app web instalable (PWA), con modo noche y un diseño basado en pinturas de paisajes.

## Desarrollo

```sh
bun install
bun run dev
bun run test
bun run build
```

Idioma: español e inglés, se elige por dispositivo (chip ES/EN arriba o desde el menú).
